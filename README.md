# UpPaper
PaperMCの新バージョンを通知します。サーバー情報を見るコマンドも追加します。

## 前提
- [dnCoreV6](https://github.com/Necnion8/dnCoreV6) (v6.1.2 以上)
- [TimerLib](https://github.com/Necnion8/TimerLib) (未導入でもサーバー情報は表示可)

## コマンド
- `uppaper [type] [version]` でサーバー情報を表示できます
- ルーム管理者は `setting uppaper` で通知チャンネルを設定できます
